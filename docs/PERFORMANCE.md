# Experience performance — v1.0.1

The mobile performance update preserves the interface, fixed coordinates,
recording-context colors, playback audio, photos, and Analysis behavior.
It changes Experience's rendering and loading only.

- Apply the same 2 px blur to the halo trace as a group, instead of applying
  440 independent SVG filters. This reduces painting work during pan and pinch.
  Blending at overlapping halos can differ slightly; marker geometry is unchanged.
- Load Plotly's basic bundle, at the same 4.1.1 version. It supports the scatter
  traces and interactions used here; Analysis continues using the full bundle.
- Omit Analysis's two comparison-ranking arrays from Experience's payload.
  The smaller payload is generated by `python3 scripts/build_experience_data.py`.
  Release validation requires every retained value to equal the full data.
- Reuse fixed coordinate/color arrays, send selection changes to the ring trace,
  and combine size notifications through one animation-frame callback.

## Measurements

Three alternating before/after trials used Chrome on macOS, a 390 × 844 viewport,
device scale factor 3, 4× CPU throttling, and disabled cache. Files were served
over local HTTP. This was not a physical-phone or mobile-network benchmark.

| Metric | v1.0.0 | v1.0.1 |
| --- | ---: | ---: |
| Loaded JavaScript, uncompressed | 6.44 MB | 1.36 MB |
| Time until map ready, median | 2,353 ms | 656 ms |
| Pan frame gap, median of trial p95 values | 100 ms | 33 ms |
| Frames over 50 ms in the scripted pan, median | 18 | 1 |
| Zoom-button latency, median | 107 ms | 101 ms |

The main measured improvement is smoother movement and faster initialization.
The zoom-button improvement is small; these results do not establish a speedup
on every phone. Full-resolution measurements are in
[performance-v1.0.1.json](performance-v1.0.1.json).

## Regression checks

Touch selection and playback, pan, pinch, zoom/reset, preservation of the view
when changing selection, rapid selections, portrait/landscape changes, picker
filtering, and the selected-recording handoff to Analysis were exercised.
Desktop A/B playback, filters, candidates, credits, and 320 px layout were also
checked. Saved coordinates and all recording media remain unchanged.

Initial and selected desktop/mobile screenshots were compared against v1.0.0.
The layout was preserved; small differences are confined to halo rendering.
No physical iOS or Android device was available for this verification.
