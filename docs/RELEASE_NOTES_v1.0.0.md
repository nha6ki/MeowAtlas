# MeowAtlas v1.0.0

This first release presents a static listening atlas of all 440 CatMeows v1.0.2
recordings from 21 cats.

- Experience: a zoomable map with recording-context colors, point selection,
  audio playback, cat profiles, and a searchable recording list.
- Analysis: A/B audio selection, aligned spectrogram comparison, filters, and
  near/far candidates based on feature or map distance.
- One shared, fixed Mel-plus-UMAP embedding, with no artificial coordinate adjustment.
- Dataset methods, interpretation limits, per-image credits, and separate third-party terms.
- Offline runtime assets and reproduction instructions for the adopted audio features.

The interface is in Japanese. Recording contexts are not emotion labels, and
map distance is not a validated measure of perceptual similarity. Illustrative
photographs do not depict the recorded cats.
